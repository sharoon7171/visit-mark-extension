Privacy Policy

VisitMark — Highlight visited links with custom colors

Last updated: April 1, 2026

Introduction

This policy describes how the VisitMark browser extension (“the extension”) handles information. “We,” “us,” and “our” refer to the extension publisher. The extension runs only in your browser using Chrome extension APIs. It customizes how visited links appear on websites you open. It does not send your browsing data to servers we operate.

Scope

This policy applies to the VisitMark extension as distributed for Google Chrome. It reflects how the current version of the extension is built to behave in code. If the extension changes in ways that affect data practices, we will update this page and the “Last updated” date.

Information the extension processes

The extension may process the categories below. Processing is limited to what is needed to apply your settings and update highlights when you navigate.

Settings you save

The extension stores your preferences in Chrome’s synchronized extension storage (chrome.storage.sync), including default highlight color, global on or off state, optional feature toggles (such as history-based highlighting and native visited styling), and per-website overrides (hostname, whether site-specific colors apply, and the color for that site when enabled).

Tab and navigation signals

To know when to refresh highlighting, the extension uses APIs that expose tab identifiers, page URLs, when a tab finishes loading, when you switch tabs, and main-frame URL changes in single-page applications (for example chrome.webNavigation history state updates). These signals are used only to decide when to run the extension’s own logic on the affected tab.

Link addresses on pages you visit

On http and https pages, injected scripts collect the resolved href values of a[href] elements so the extension can determine which links to style. This happens in the page context your browser already loaded; those values are not transmitted to us.

Optional use of browsing history (Chrome History API)

If you turn on history-based visited detection in the extension popup, the extension calls chrome.history.getVisits for candidate URLs derived from links on the page to see whether Chrome’s history contains matching visits. It also listens for history add and remove events so highlights can update. If you leave this option off, the extension does not perform these history lookups for that purpose.

How we use this information

We use the information above solely to provide the extension’s features: applying and updating visited-link appearance according to your settings. We do not use it for advertising, sale of personal data, or to build profiles about you for unrelated purposes. The extension does not include analytics or remote logging to our systems.

Storage and retention

Your saved settings remain in Chrome (and, if you use Chrome sync while signed in, may sync according to your Google account and Chrome settings) until you change them, remove the extension, or clear extension data through Chrome. History queries performed by the extension are used to compute highlighting on the device and are not stored by us.

Sharing and third parties

We do not receive your full browsing history, page HTML, or lists of links from websites. We do not sell personal information.

Google provides Chrome, the extension platform, synchronized extension storage when sync is enabled, and the History API. How Google processes data in Chrome is governed by Google’s policies and your Chrome and Google account settings, not by this document.

Your choices

  • Disable history-based detection in the extension popup if you do not want the extension to query the History API.
  • Turn highlighting off globally or adjust per-site options in the popup.
  • Remove the extension or clear browsing and extension data using Chrome’s settings.

Changes to this policy

We may update this policy when the extension or applicable requirements change. The version published at this URL, together with the “Last updated” date above, is the one in effect.
